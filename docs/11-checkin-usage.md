# 打卡使用说明（给家人）

> 面向「每天练完投个视频/录音」的日常使用，不涉及技术细节。设计见 [10-checkin-plan](10-checkin-plan.md)。

## 一句话

**练完录一段，AirDrop 到家里那台 Mac mini，就自动打上卡了。** 不用打开 App、不用点提交。

## 怎么录

| 项目 | 录什么 | 时长 |
|---|---|---|
| 每日阅读 | 朗读故事书（有人在读的声音） | ≥ 1 分钟 |
| 二胡练习 | 拉练习曲/曲子（几乎没人说话） | ≥ 1 分钟 |

- 手机自带相机/录音机录都行，横竖屏都可以。
- 太短的（< 60 秒）不会被当成打卡，会原样留在电脑的「下载」里。
- 一次练习可以录多段，同一天的会自动合并到同一条记录（时长累加）。

## 怎么投

iPhone/iPad：相册（或文件）→ 分享 → **AirDrop** → 选家里的 Mac mini → 「保存到下载」。
iPad/安卓：同一 Wi-Fi 下用 AirDrop 类似功能、微信「文件传输助手」发到电脑后放进「下载」也可以。

## 投完会发生什么

1. 30~60 秒内自动出现在 **网页**（`https://www.whereami.cn/tools/checkin/`）和小程序「打卡」页。
2. 认出来了 → 直接记为「已打卡」，视频在线可看（云端只留 7 天，原件永久在电脑里）。
3. 没认出来 → 进「待认领」，点开预览听/看一眼，选「指派到…」即可。
4. 补上书名/页码、曲名/遍数，归档文件名会自动变成
   `2026-11-06_二胡练习_赛马x5_IMG_1240.MOV` 这种好找的样子。

## 文件放在哪

- 原件归档：Mac mini 的 `~/cijian-archive/<年-月>/`，**永久保存**，不占云端。
- 预览片：云端 7 天自动清理；过期后网页/小程序里仍能看到记录，只是不能在线播放。
- 不是打卡内容（误投、太短、解析失败）：**原地留在「下载」里，不移动、不删除**；
  待认领里点「忽略」即可。

## 出了小状况

- **投了没反应**：等 1 分钟；确认 AirDrop 是「保存到下载」；确认 Mac mini 醒着（合盖睡眠时不处理，醒来会补）。
- **被认成另一个项目**：网页/小程序里点「改派」，归档名会自动跟着改。
- **想多记一样东西**（比如「天气」）：网页「项目管理」里加字段，不用改代码。
- **今天的记录想改日期**：网页版可改（小程序暂不支持改日期/删除）。

## 第一周观察清单（M-C5）

- 每天是否都能自动认出项目（目标：待认领 < 10%）。
- 预览片能否顺畅在线播放（手机流量/Wi-Fi 各试一次）。
- 字段填写是否顺手（书名/页码、曲名/遍数）。
- 是否需要「没有媒体时手动补卡」（第一周先不做，观察真实需求）。
