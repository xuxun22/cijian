# 02 · 打印功能 PRD

> 需求来源：2026-10-21 用户补充。状态：已确认。

## 背景与目标

在多个地点（家中、老家等）各有一台打印机与一台常驻服务器。希望从任何地方（站点登录后）把一张照片或一份文档发到指定地点打印，并知道打印结果。

## 用户故事与验收标准

### US1 · 登录

> 作为家人，我输入口令进入私有区，避免陌生人操作打印。

- 输入正确口令 → 获得 token（7 天有效），进入打印工作台
- 错误口令被拒，且限速：同 IP 每分钟最多 5 次
- token 过期后所有私有接口返回 401，前端引导重新输入
- 公开内容不受影响

### US2 · 上传

> 作为登录用户，我上传一个文件作为打印内容。

- 类型白名单：`pdf` / `jpg` / `png`；超出白名单返回 415
- 大小上限 20MB；超出返回 413
- 文件入库，24 小时后过期清理；过期时间对用户可见
- 前端支持点击选择与拖拽

### US3 · 选择打印机地点

> 作为登录用户，我看到打印机列表并选一台。

- 列表显示：名称、地点、是否在线（60 秒内有过心跳 = 在线）、能力（黑白/彩色）
- 允许向「离线」的打印机提交——任务排队，等它上线后自动打；但前端给出醒目提示「该打印机当前离线，将在其上线后打印」

### US4 · 提交打印

> 我选好文件和打印机，提交打印任务。

- 参数：份数（默认 1，1–20）、色彩（默认 auto=按打印机能力）、单双面（默认 auto）
- 提交成功立即返回 `job_id`，状态 `queued`
- 同一文件 + 同一打印机 3 秒内重复提交，前端拦截提示

### US5 · 查看状态

> 我在打印任务列表里看到每单的进度。

- 列表按时间倒序，展示：文件名、打印机（名称+地点）、状态、提交时间
- 状态：`queued 等待` / `claimed 已接收` / `printing 打印中` / `done 完成` / `failed 失败` / `expired 文件过期`
- 失败显示原因文本；点开可看状态时间线（谁在何时把状态改成了什么）
- 任务与时间线保留 30 天后清理

## 结果口径（ADR-005）

「查看打印结果」= **任务状态与文本原因**，不拍照/扫描回传影像。

## 非目标

- 打印预览渲染、页码范围选择
- 多用户与权限区分
- 影像回传（拍照证明）
- 计费 / 配额 / 用量统计

## 边界与异常

| 场景 | 行为 |
|---|---|
| 文件在任务完成前过期（24h） | 未开印的任务标记 `expired`，不再派发 |
| Agent 掉线 | 任务停在 `queued`，不迁移到其他打印机（一地一机） |
| 打印失败（卡纸、缺纸、离线超时） | 自动重试，累计 ≤3 次后标记 `failed` |
| Agent 领任务后崩溃 | 租约（120s）超时后由 API 重派；重派前 agent 若恢复，以「本地无此任务」放弃，不重复打印 |
| 打印超时（提交 CUPS 后 10 分钟无完成） | Agent 上报 `failed`，原因「打印超时」 |

## 端到端验收清单

1. 登录 → 上传一张照片 → 选「老家」打印机 → 提交
2. 老家服务器 agent 自动领取 → 照片出纸
3. 站点任务列表状态流转 `queued → claimed → printing → done`
4. 断开老家 agent 再提交一单：状态停留 `queued`；agent 恢复后自动完成
5. 提交一个损坏 PDF：任务 `failed`，原因可读
6. 24 小时后：文件被清理，已完成任务仍可查（30 天）
