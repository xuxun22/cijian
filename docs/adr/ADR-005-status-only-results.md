# ADR-005 · 打印结果：仅状态回传，不回传影像

日期：2026-10-21 · 状态：已接受（用户选定）

## 背景

「查看打印结果」可有两种口径：① 任务状态与失败原因；② 打印件拍照/扫描回传影像。

## 决策

只做 ①：agent 上报 `done/failed + 文本原因 + lp 返回码`，不做影像回传。

## 后果

- ✅ 无需在打印机旁加摄像头/扫描环节，硬件与实现成本大幅下降
- ✅ 隐私面更小（不产生打印件影像的存储与传输）
- ✅ 失败原因（卡纸、缺纸、超时）已覆盖「要不要重打」的判断需要
- ⚠️ 「打出来效果如何」不可见——照片打印对色彩有要求时，靠现场人眼验收
- 🔁 若未来需要：加 `photo` handler，由带摄像头的地点上报影像——架构上已预留（处理器注册表）
