# ADR-007 · 文件存储：本地磁盘 + TTL（不引入对象存储）

日期：2026-10-21 · 状态：已接受（沿用现状设计）

## 背景

打印文件是**中转数据**：上传 → 打印 → 无长期价值。现有 api 服务器已用「临时本地文件」作为存储。

## 决策

- 上传文件落 `DATA_DIR/files/`，随机名存储，带 24h TTL
- 只能通过 HMAC 签名短时 URL（15 分钟、绑定任务与地点）读出，无公开读路径
- sweeper 每 10 分钟清理过期文件；磁盘水位 >90% 拒收新上传
- 不使用对象存储（COS/S3），不做跨机冗余

## 后果

- ✅ 零额外成本与依赖；架构与现有服务器形态一致
- ✅ 隐私友好：文件即焚，不留长期副本
- ⚠️ api 重装/迁移时文件丢失——可接受（未打印任务重传即可）
- ⚠️ 磁盘被照片打满的风险由 TTL + 水位双保险兜住（05 §Sweeper）
