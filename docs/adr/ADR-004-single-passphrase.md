# ADR-004 · 登录：单口令 + JWT

日期：2026-10-21 · 状态：已接受（用户选定）

## 背景

私有功能（打印工作台）的使用者是家人，个位数规模，无角色区分需求。

## 决策

- **单口令**：hash（argon2id）存 api 环境变量，明文不落任何存储
- 登录成功签发 **JWT**（HS256，7 天）；无刷新令牌，过期重输
- 登录限速 + 指数退避防爆破

## 备选与否决

- **账号密码多用户**：家庭规模无权限差异，纯增熵
- **GitHub OAuth**：家人未必都有 GitHub 账号，且引入第三方依赖
- **Magic link（邮件）**：需邮件服务，且口令更直接

## 后果

- ✅ 实现与使用成本最低；家人只需记一个口令
- ⚠️ 口令即全家共享凭证，泄露影响面 = 全部私有功能——以限速与轮换缓解
- ⚠️ 无法区分「谁提交的打印」——家庭场景可接受，需要时升级多口令
