# 01 · 站点定位

## 一句话

**此间**（whereami.cn）：记录所学、收藏生活的个人与家庭站点；对内另有一扇登录后的小门，提供家庭工具——第一个是远程打印。

## 双重身份

| 面 | 内容 | 谁能看 |
|---|---|---|
| 公开面 | 所学（知识笔记）、生活（家庭记忆）、关于 | 所有人，无需登录 |
| 私有面 | 打印工作台：上传文件/照片 → 选打印机地点 → 提交 → 看状态 | 仅家人（单口令登录） |

公开面是「此间」的本体——此时、此地、此生的所学所思与家庭记忆；私有面是附在旁边的「家庭工具箱」，打印只是第一件工具，后续可按需增加。

## 受众

- **主要**：我自己与家人。登录功能的使用者，规模个位数，无需多用户体系。
- **次要**：互联网访客。只读公开内容，永远看不到私有面。

## 内容原则

- 公开内容保持现有站点设计：纸·墨·朱砂，宋体气质，节气点缀（见现站点）。
- 私有功能区不必坚持文人气，以「好用、清楚」为先，视觉上与公开面同源即可。
- 内容即 Markdown，代码仓即真相源。

## 域名与入口

| 入口 | 指向 |
|---|---|
| `whereami.cn` | Vercel 上的站点（cijian-site） |
| `api.whereami.cn`（方案待定，见 06-security §传输） | 腾讯云 API（cijian-api） |
| 无公网入口 | 各打印机地点服务器（cijian-agent，纯出站） |

## 非目标

- 多用户 / 社区化 / 评论
- 移动 App
- 对公网开放的 API
- 打印计费与配额
