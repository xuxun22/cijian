# ADR-001 · Agent 采用纯拉取式通信

日期：2026-10-21 · 状态：已接受

## 背景

每个打印机地点有一台常驻服务器，需要接收 api 派发的任务并上报状态。地点服务器通常在家庭宽带 NAT 之后，无公网 IP。

## 决策

Agent **只发起出站连接**（心跳 30s、主动领任务、主动上报），api 永不主动连接 agent。地点服务器不开任何入站端口。

## 后果

- ✅ 天然穿透 NAT，无需公网 IP、端口映射、frp 等隧道
- ✅ 攻击面最小：地点服务器在公网不可见
- ✅ 心跳同时充当在线状态数据源（PRD US3 的「在线」）
- ⚠️ 任务延迟下限 = 轮询间隔（30s，家用可接受）
- ⚠️ 心跳/领取需要限速与认证防滥用（06-security）
